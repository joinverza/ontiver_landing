# Bricolage Grotesque

Original Google Fonts Latin WOFF2, self-hosted without modifications.

- Designer: Mathieu Triay.
- License: SIL Open Font License 1.1; see `OFL-BricolageGrotesque.txt`.
- Included axes: weight 200–800 and optical size 12–96; width is the normal 100% instance.
- CSS uses `font-optical-sizing: auto` so optical size follows the rendered text size.
- Glyphs outside the Latin subset use the site's system-font fallback.
